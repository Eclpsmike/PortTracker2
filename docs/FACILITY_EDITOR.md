# Facility floor plan editor

Run `npm install` and `npm run dev`, then choose **Facility** in PortTracker's top navigation (`#/facility`). Use Node 22. The existing rack pages and saved rack records remain available.

The first visit opens a populated single-floor example with rooms, an IDF, wall plates, access points, a camera, a printer, and planned routes. Its architectural drawing is based on the supplied handoff SVG. The editable overlays are separate from the source drawing.

## Working with a drawing

- With multiple items selected, **Properties → Arrange** provides **Align horizontally**, **Align vertically**, **Increase spacing**, **Decrease spacing**, and **Distribute evenly**. Alignment uses centers, independent of label size. Choose **Spacing direction** for a row or column; alignment selects the matching direction automatically. Spacing changes use the current grid interval, preserve order and group center, and stop at a minimum of one grid interval or the drawing boundary. Even distribution requires three items and keeps the outermost centers fixed. Locked items and paths are excluded; attached paths follow moved objects. Each action supports Undo/Redo.
- The sample background has no decorative grid; **Show grid** displays the editor's grid. With **Snap to grid** enabled, dragging snaps a symbol's center to grid intersections, including items placed before the spacing changed. Group moves snap the dragged item's anchor and preserve relative spacing. Changing grid spacing alone does not reposition existing objects.
- Location boxes have a **Ports** accordion directly below **Unplaced objects**, showing labels, current VLANs and patch status. It includes ports on SMBs and wall plates assigned to that location, even on hidden layers, plus unplaced rack ports assigned there. Links to the same rack port appear once, with all source items named. Unlinked map ports remain visible as **Not linked**.
- Choose **Speaker** in Drawing tools to place a speaker symbol on the Devices layer. Speakers support persistent tool sizing, location inheritance, notes, appearance controls, four-side path connectors, filtering, and drawing export/import.
- Select a drawing tool on the left, then click or drag on the plan. SMBs support 1–8 ports. Clicking the plan with the SMB tool opens **Set up SMB**. Choose an active **IDF / MDF prefix**, then enter an inclusive **Port range** (for example 225–232) or up to eight **Individual ports**. The preview pads the number to three digits (B001, B012, B225); **Place SMB** saves the selected frame and each patch-panel port number. Duplicate numbers, reversed ranges and more than eight ports are rejected. **Configure later** places one unconfigured port; **Cancel** or Escape leaves the plan unchanged. Frames without a prefix are listed but unavailable for immediate setup; configure their prefixes in Distribution Frames, or choose Configure later. Afterward, **Properties → Ports** shows a table of eight rows with port numbers, labels, live VLANs and patch status. VLAN comes from the linked patch-panel port’s connected switch port. **Patched** means a rack cable is connected; **Unpatched** means the linked panel port is free; **Not linked** means there is no unique patch-panel match. A dash indicates no assigned VLAN or an unused slot. These columns update from rack changes; manual mapping status and saved floor VLAN notes do not override them. For SMBs, **Termination & VLAN** also reads the rack name, patch-panel name and prefixed port, connected switch name/interface, and VLAN directly from rack records. **Change patch-panel link** lets you select the frame and exact panel port, including resolving duplicate port numbers across racks. Unpatched ports show no switch or VLAN; missing or ambiguous links are identified without guessing. Click a port row to edit its settings, or **Add port** in the next unused row to add a port. Use the **×** button on any populated row to remove that port after confirmation. Remaining ports retain their labels, IDs, notes and links; the rack port and its cable connection are preserved. Removal supports undo/redo, and the SMB retains at least one port. SMBs receive identifiers such as `SMB-003`, with individual port labels `SMB-003-1` through `SMB-003-8`. Removing a port requires confirmation and supports undo. Wall plates support 1, 2, 4 or 6 ports. Every new port starts unmapped; IDF, patch panel, switch, VLAN and route information can remain unknown.
- For an **IDF / Rack** marker, use **Properties → Distribution frame** to select an available configured IDF or MDF. The marker takes that frame’s name and saves its reference. All items show their name or frame selection, location, notes and item-specific properties above separate **Symbol**, **Label**, **Placement** and **Layer properties** accordions. Symbol contains size, color and route line weight; Label contains label styling; Placement contains position and rotation; Layer properties contains layer assignment. Routes omit the Label and Placement accordions. Port details and route connections remain above these groups. Hover the appearance fields for help. Add frames in **Distribution Frames** first.
- Select an object to edit its properties on the right. Drag markers and rooms to move them. Selected rooms have corner resize handles; selected paths have editable vertices. Items show their inherited room name in **Room / location**, using the smallest location box containing their anchor point. Moving an item or moving/resizing a box updates the inherited location; the port table and location filters use it too. Routes inherit only when all their vertices are inside one box. Hidden or locked boxes still define locations. Choose a specific room or **Unassigned** to override inheritance, or choose **Follow location box** to restore it. Existing explicit assignments are preserved. Parent locations for location boxes remain explicit.
- Shift-click or drag a selection box to select multiple objects. Duplicate creates new object and port IDs and unique port labels; port mappings and route endpoint references are cleared on copies.
- Click successive points to extend a cable path, tray or conduit with direct segments at any angle, including diagonals. A preview follows the pointer from the last point. When calibrated, the current segment’s length appears beside the preview in the selected feet or meters and updates as you move, including on diagonals. Drawing continues until you choose **Finish path** or press **Enter**; double-clicking does not finish it. **Escape** cancels the unfinished route. Dragging a saved route vertex moves that point without shifting neighboring points. Routes start planned. Marking a route verified does not change port verification.
- Equipment symbols have top, right, bottom and left connectors. They appear when equipment is selected or when drawing/editing a route. Start or end a cable path, tray or conduit on a connector to snap to the symbol edge and populate **Source** or **Destination**. Connector snapping takes priority over grid snapping. Attached endpoints follow equipment movement and resizing; intermediate vertices stay where you placed them. Drag an endpoint to another connector to reconnect, or away to disconnect. These links save with the drawing and support undo, duplication and deletion. Existing manual endpoint references remain available and do not imply a physical attachment or verify any ports.
- Use **Layers** to show, hide, lock, rename, recolor and reorder groups. Lower layers draw on top. Add a custom layer, then assign objects through Properties or select it as the Drawing layer. Removing a populated layer requires confirmation and reassigns its objects.
- **Filters** independently restrict rooms, object types, mapping status, IDFs and known VLANs. Filters and hidden layers never remove saved data.
- **Search**, above the sidebar tabs, finds items by name, ID, type, notes, room, port label or linked distribution-frame name/prefix. Select a result to center it on the map and open Properties; Enter selects a sole result. Selecting a result clears filters and reveals its layer if hidden, without unlocking it. Clear the search with the × button or Escape.
- **Location box → Unplaced objects** lists patch-panel ports assigned to that room in the rack workspace but not linked to an item on this map. The list includes the port label, distribution frame, rack, panel and notes; map-placement controls will be added separately. Once a port is linked to a placed SMB or wall plate, its effective map location controls the rack location, including replacing an existing conflicting assignment. Moving the item, changing its room or renaming that location updates its linked rack ports. Notes are preserved. Removing the map item keeps the last rack location and returns the ports to the unplaced list. Rack controls identify map-controlled locations and preserve them during bulk location edits. Links use the IDF and unique patch-panel number, or explicit rack/panel references. Ambiguous numbers or duplicate links in different map rooms require correction before synchronization.
- **Calibrate scale** uses two selected points and a known distance in feet or meters. Measure and route lengths remain uncalibrated until scale is set. Display units can change without altering calibration. These lengths describe the drawn floor path, excluding rack runs, slack and bend allowances.
- Select a marker tool (SMB, wall plate, IDF/rack, access point, camera, printer or device), then set **Symbol width** on the left. Each tool remembers its own size for new items; changing a default does not resize items already placed. Before calibration, width is shown in plan units; afterward it uses feet or meters. Defaults save with the drawing and survive reload and JSON import/export. Symbols and labels zoom with the drawing.
- Select **Cable path**, **Cable tray** or **Conduit** to set its own **Line weight (plan units)** on the left. Preview lines and new routes use that weight, and endpoint/vertex dots scale proportionally. Select an existing route and use **Properties → Symbol → Item line weight** to resize its line and dots together.
- Use **Select** to drag a device by its icon or label. Turn **Snap to grid** off to position it freely.
- Select a port or device and use **Properties → Symbol → Item symbol width** for an individual size in calibrated feet or meters (plan units before calibration). Drag a corner handle for proportional resizing around the same location. **Use default symbol width** applies that tool’s current saved width to the selected item. Room width and height fields also use calibrated units. Size edits support undo and save with the drawing; locked layers cannot be resized.
- **Properties → Label** controls each label's font size, placement and X/Y offsets. Device labels can sit above, below, left, right or centered; room labels support corners and center. Positive offsets move right/down. Standalone text labels support font size and offsets too. Labels zoom with the plan, and device labels scale with their symbols. Selection bounds follow the new label position. Changes support undo, save/export and locked layers; **Reset label style** restores the defaults without moving the item.
- Selection outlines enclose the icon and label. Drag empty space, including room interiors, to select items fully enclosed by the selection rectangle; selection does not snap to the grid. Move rooms using their header or border. Shift adds to a selection. Invisible oversized click targets and browser focus outlines do not extend the selection area.
- **Grid spacing** accepts a numeric distance between grid lines. After calibration, **Grid units** can be feet or meters. Changing grid spacing or units leaves existing items, room geometry and cable paths untouched; only later placements and moves use the new snapping interval. Grid settings save with the drawing. If calibration is cleared, a physical-unit grid temporarily uses 10 plan units until recalibrated.
- Fit plan resets pan and zoom. Switching drawing tools or resizing the workspace preserves the current view. The zoom percentage controls only the view; use Calibrate scale to configure real-world measurements. Use two-finger touchpad scrolling to pan horizontally or vertically. Pinch or Ctrl+scroll zooms around the pointer; touchscreen pinch also zooms. You can also use Pan or hold Space to pan. Grid snapping uses plan coordinates, independent of zoom. Turn it off for precise image alignment.
- **Rotate / crop** opens an image preview. Rotate left or right in 90° steps, or drag a crop rectangle and choose **Crop to selection**. Numeric crop fields are also available. **Apply image changes** saves the preview as one undoable edit; Cancel leaves the drawing untouched. Rotation and cropping transform all overlays, including hidden and locked layers, so they stay aligned. Crops that exclude objects are blocked. Calibration is preserved unless cropping removes one of its reference points, in which case the scale is cleared. The original uploaded file remains available for download.
- Set **Port prefix** in **Distribution Frames → Add/Edit distribution frame** (for either MDF or IDF). For a facility port, assign its **IDF / distribution frame** and **Patch panel port** under **Termination & VLAN**. Prefix `B` and patch-panel port `225` display as `B225` in Properties, Network ports, search and map tooltips. A numeric existing port label also works when the patch-panel port is unknown. Labels follow prefix changes automatically; original labels, internal IDs and mappings are retained. The SMB marker keeps its own `SMB-###` identifier. Prefixes and floor drawing frame references save together in the unified project backup.
- Expand **Network ports** for a searchable table of visible ports and any known terminations.

Shortcuts, outside form fields: **V** select, **H** pan, **O** SMB, **R** location box, **C** cable path, **M** measure, **T** label; **Ctrl/Cmd+Z** undo, **Ctrl/Cmd+Shift+Z** or **Ctrl/Cmd+Y** redo, **Ctrl/Cmd+D** duplicate, **Delete/Backspace** delete, **Ctrl/Cmd+S** save, **Escape** cancel the current drawing or selection.

## Files and persistence

**Change plan** accepts PDF, PNG, JPEG, SVG and WebP files up to 25 MB. PDFs provide a page selector; one selected page becomes this floor's background. SVG uploads are decoded in an image context and rasterized, never inserted as executable page markup. The original upload is retained for download. Raster previews are capped at 3,200 pixels on their longest edge; PDF previews at 2,400 pixels. Changing a background resets calibration. Overlays can be retained only when dimensions match; the user must also verify alignment.

PDF.js and its font, character-map and decoder resources are bundled locally, using the library's [document loading and rendering API](https://mozilla.github.io/pdf.js/examples/). Uploads are processed in the browser.

Existing automatically generated `PORT-###` SMB names convert to `SMB-###` on load or import, avoiding identifiers already in use. Matching default port labels convert too; custom labels, internal IDs, mappings and route references are preserved.

Drawings autosave in IndexedDB, keyed to the current PortTracker project ID. **Save drawing** explicitly retries saving. Storage failures are visible; unreadable saved drawings are not overwritten automatically.

**Export project** in either workspace creates one backup with all rack records, configuration, templates, saved preferences, and the current floor drawing—including overlays, layers, ports, geometry, calibration, grid/tool defaults, background, and original uploaded file. Pending drawing saves and edits retained in memory after a save failure are included. An unreadable drawing blocks export rather than silently producing a rack-only backup.

**Import project** restores a combined backup after validation and confirmation. It also accepts older drawing-only JSON (including the handoff sample); those files replace only the drawing and keep rack records. For old separate backups, restore the rack project first, import the old drawing in Facility, then export a unified project backup. A rack-only backup is identified as missing a drawing before replacement. See [Project backup coverage](PROJECT_BACKUP.md).

Examples: [`sample-floorplan.svg`](../public/facility/sample-floorplan.svg) and [`sample-project.json`](../public/facility/sample-project.json). Browser checks produce `artifacts/facility-desktop.png` (1440×900) and `artifacts/facility-mobile.png`.
